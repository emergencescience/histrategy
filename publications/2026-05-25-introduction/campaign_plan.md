# Emergence Science + HiStrategy 联合品牌宣发双轨营销周计划

本方案旨在为**涌现科技（Emergence Science）**及旗下开源项目**《三國志略》（HiStrategy）**制定为期四周的冷启动与品牌建设双轨方案。我们将“硬核技术硬实力展示”与“大众化游戏叙事趣味”深度结合，以“大模型降价潮下的创新实践”为切入口，全力打造涌现科技在**智能体经济（Agent Economy）**领域的品牌影响力。

---

## 🎯 宣发双轨战略定位

1.  **技术轨（Emergence Science）**：面向开发者、AI 创业者、技术投资人。主打“多智能体系统（MAS）设计”、“高可用 Agent 架构”、“低成本大模型仿真推演”。
2.  **游戏轨（HiStrategy）**：面向三国志玩家、策略游戏发烧友、独立游戏圈。主打“自由输入命令”、“无剧情模板的《建安异录》”、“真实世界因果模拟”。

---

## 📅 4周 Campaign 推广时间表

### 🗓️ 第一周（Week 1）：极客冷启动与开源造势
*   **宣发重点**：技术硬实力背书，通过 GitHub 开源与高质量文章建立第一波极客心智。
*   **执行动作**：
    *   **Day 1 (博文发布)**：在知乎、涌现科技官网（Articles）、V2EX、稀土掘金发布知乎推文草稿与技术文章《大语言模型驱动的历史策略仿真引擎与自主叙事游戏设计实践》。
    *   **Day 3 (视频发布)**：在 Bilibili 发布 5 分钟实机解说视频，重点演示“自由输入决策”与“实时 reasoning token 抓取（让 AI 思考透明化）”。
    *   **Day 5 (社群发布)**：在 V2EX 的 `AI` 节点与 `Share` 节点发帖：“*一局推演不到5分钱！我们做了一款纯 DeepSeek 驱动的三国策略游戏，代码已全部开源*”，附带 GitHub 链接，求 Star 并吸引种子用户。
*   **KPI 指标**：GitHub Star > 30，B 站视频播放量 > 2,000。

---

### 🗓️ 第二周（Week 2）：KOL 体验与“名场面”裂变
*   **宣发重点**：通过 KOL（关键意见领袖）的试玩和自来水，向垂直受众（游戏玩家、科技发烧友）辐射。
*   **执行动作**：
    *   **Day 1 (KOL 定向 Pitch)**：
        *   **AI/技术圈**：联系微信公众号（如*机器之心*、*量子位*）以及知乎 AI 大 V，提供技术文章和 Demo，主打大模型降价后的应用创新案例。
        *   **独立游戏圈**：私信 B 站的三国/策略类游戏 UP 主，提供定制化的 JSON 剧本（如“UP主大闹虎牢关”），邀请他们录制整活试玩视频。
    *   **Day 3 (社群互动)**：在知乎发起问题或在现有问题下作答：“*如何评价用大模型（如 DeepSeek）来做策略游戏的物理引擎？*”
    *   **Day 5 (趣味裂变)**：在社交平台发布“名场面吐槽墙”，贴出 AI 生成的《建安异录》搞笑推演文案（例如“刘备在平原开荒，张飞带兵打黄巾顺便抢了袁绍的迎亲队伍”等），引发玩家跟帖转发。
*   **KPI 指标**：GitHub Star > 70，获得至少 2 位 KOL 转发或视频推荐。

---

### 🗓️ 第三周（Week 3）：开发者 Mod 大赛与开源共创
*   **宣发重点**：激发社区的创造力，利用项目的模块化（JSON）设计，将用户变成内容生产者。
*   **执行动作**：
    *   **Day 1 (Mod 大赛启动)**：在 GitHub 和知乎正式发起“《建安异录》Mod 设计大赛”。
        *   规则极简：玩家只需根据 `knowledge/` 下的 JSON 格式编写一个自定义的势力、武将或事件文件，提 PR 即可参赛。
    *   **Day 3 (技术拆解博文)**：发布技术专栏，详细讲解《三國志略》中的“WorldState 状态自治状态机设计”和“如何用 Markdown 融合复杂 JSON 数据”，展示涌现科技底层的工程高标准（全测试覆盖、Robust 自动降级设计）。
    *   **Day 5 (Mod 成果展示)**：在 B 站和知乎展示社区提交的优秀魔改剧本（例如“赛博三国”、“现代武器穿越剧本”），展示游戏在模块化架构下的强大可塑性。
*   **KPI 指标**：GitHub PR 数量 > 10，Star 数量接近 100。

---

### 🗓️ 第四周（Week 4）：Star 破百兑现，发布 OpenClaw（小龙虾）连接
*   **宣发重点**：将 HiStrategy 的热度全面收拢、平移并导流到涌现科技下一代核心平台级产品——**OpenClaw（小龙虾）**。
*   **执行动作**：
    *   **Day 1 (破百贺图与预告)**：庆祝 GitHub Star 突破 100 个。发布“小龙虾客户端即将来袭”的预告海报。
    *   **Day 3 (OpenClaw 版上线发布)**：正式发布《三國志略》OpenClaw 智能体连接器。
        *   用户可以直接在微信群、飞书或 Telegram 窗口中输入自然语言命令，后台的“小龙虾”系统会自动接入 HiStrategy 引擎完成回合推演并把古风叙事和数据以微信消息的形式实时推送回来。
    *   **Day 5 (终极收官博文)**：在知乎和官网发布深度行业文《从命令行三国到小龙虾 IM 智能体：智能体经济（Agent Economy）已迈向消费级落地》，向行业正式推介**涌现科技（Emergence Science）**在生产级多智能体系统与即时通讯智能体（IM Agent）的核心交付实力。
*   **KPI 指标**：GitHub Star > 150，小龙虾体验用户数 > 500。
