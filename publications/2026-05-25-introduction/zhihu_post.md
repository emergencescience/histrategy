# 历史不由剧本决定：用大模型直接做游戏“物理引擎”，是一次怎样的革命？

在传统的历史策略游戏里，不论是《三国志》还是《文明》，玩家面对的都是一张张写死的规则网。你选择“屯田”，粮草增加；你选择“联姻”，判定友好度。

游戏设计师像一位全知全能的上帝，提前在配置表里写好了所有的历史走向与分支。只要玩得够久，玩家就能摸清所有的规则套路，世界最终退化为冰冷的数值对撞。

**如果，我们把写死的剧情分支和判定规则全部废除呢？**

作为探索**智能体经济（Agent Economy）**的先驱团队，我们**涌现科技（Emergence Science）**做了一次极其大胆且革命性的尝试：

**我们彻底移除底层的所有剧情模板，让大模型（特别是推理模型 DeepSeek）直接作为游戏的“物理引擎”与仿真引擎。**

我们把这套纯大模型驱动的局势推演系统做成了一款命令行策略游戏——**《三國志略》（HiStrategy）**，并在 GitHub 全面开源。

## 一、 策略游戏的范式转移：从“按图索骥”到“自治仿真”

在《三國志略》中，大模型不再是只负责说两句漂亮话的“气氛组”，它是**世界本身**，负责推演万物运转的因果律：

### 1. 废除选项：输入你作为君主的真实政令
在内政会议（Plan Mode）后，你不再需要从 ABCD 选项中做单选题。你可以直接在终端里输入任何你脑海中的战术方针。
例如：*“采纳张飞分兵建议，关张带两千人去找公孙瓒合兵南下，留简雍和孙乾在平原西郊开垦屯田，同时暗中派孙乾去联络北海孔融借粮。”*
大模型将作为世界引擎，动态理解你的命令，并计算这一举动对天下势力、部下情绪、府库物资的涟漪效应。

### 2. 演义编年史排版：把数据流动写成“史书”
我们将命令行界面重塑为一幅极简的“单幅折页古书卷”布局。大模型运算出的后果，不会冷冰冰地呈现在属性面板上，而是以文白相间的《三国志》或《建安异录》编年体风格展现给玩家。所有的资金、粮草、民心变动都会作为“历史夹注”自然地融入文本中，创造出极致的沉浸感。

### 3. 自驱动的天下大势与“偏离度”
AI 会实时评估你的决策与真实历史的偏差。一旦你打破了历史的引力，游戏将切入《建安异录》分支。大模型将摆脱正史的束缚，完全基于各方君主的性格（如曹操多疑、孙坚刚烈）和实时利益，进行完全自驱动的沙盒博弈。

## 二、 致敬先驱：从文字冒险到策略模拟的进化

在设计这款游戏的过程中，我们必须向两位优秀的行业先驱致敬：

*   **西方的《AI Dungeon》（AI 地下城）**：它是大模型生成式游戏的鼻祖，向我们展示了“输入任意文本，AI 接戏演绎”的无限自由度。但它更偏向于单兵作战的 RPG 冒险，缺乏了宏观策略游戏中对于**国家政权、地缘政治、战役兵力和府库资源**的结构化结算。
*   **近来火爆的《崇祯模拟器》**：它用文字模拟的方式重现了历史决策的惊心动魄，极富历史厚重感。然而，《崇祯模拟器》的底层依然高度依赖预设的历史事件模板和选项树。

《三國志略》的目标，正是**融合这两者的长处，并向前迈出革命性的一步**：它拥有《AI Dungeon》式的自由文本输入与动态演义生成，同时又承载了《崇祯模拟器》式的历史重力与宏观策略盘面。**我们通过设计一个高度结构化的 WorldState 状态机，让大模型在天马行空的叙事与严谨的数值状态结算之间找到了完美的平衡点。**

## 三、 大模型降价潮带来的商业化曙光

过去，由于 GPT-4 级别的模型调用成本极其高昂，这种“每一步都呼叫 LLM 运算世界”的游戏只能是实验室里的 Demo。

但今年，大模型价格迎来了雪崩式的下跌。以 DeepSeek 为代表的推理模型，将 Token 成本打到了冰点。
在《三國志略》中，单回合的双向调用（包含庞大的世界局势上下文投喂与 JSON 结构化输出）约消耗 2,000 至 4,000 Token。
按 DeepSeek 官方 API 价格折算：
* **单回合费用**：约 **0.0004 元**（0.04分钱）
* **玩整局游戏（100回合）**：大模型 API 成本**低于 5 分钱（RMB）**！

Token 降价潮让纯大模型驱动的游戏从“成本噩梦”直接变成了“人人可玩的现实”，这也为下一代文本生成游戏的爆发奠定了商业化基石。

## 四、 模块化架构与开源共创

《三國志略》采用了高度模块化的微架构设计。我们将势力配置、史实剧本、人物设定等数据完全解耦在 `knowledge/` JSON 文件中。
* **对于玩家与 MOD 作者**：你不需要懂任何复杂的编程，只需修改 JSON，就可以瞬间在游戏里插播一段属于你自己的战役或魔改剧情。
* **对于独立游戏人与开发者**：这套**“大模型驱动的局势仿真引擎”完全开源**。我们实现了健壮的 Prompt 设计、JSON 解析防护与优雅的离线降级逻辑，您可以直接将我们的引擎代码复用到您自己的 AI 游戏项目中。
