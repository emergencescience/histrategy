# 涌现科技（Emergence Science）《三國志略》宣发与运营推广方案

本项目（HiStrategy）作为涌现科技展现**智能体经济（Agent Economy）**实力的技术 Showcase，不仅是一款游戏，更是我们技术研发和工程设计能力的活广告。为了在接下来的一个月内制造网络声量，并吸引更多的高质量开发者和游戏玩家到涌现科技的品牌上，特制定本推广与运营方案。

---

## 一、 品牌定位与品牌价值打法

*   **品牌主体**：涌现科技（Emergence Science / 涌现）
*   **品牌定位**：国内领先的生产级多智能体系统（Multi-Agent System）与仿真技术先驱。
*   **宣传切入点**：
    *   **硬核工程能力**：市面上很多 Agent 演示只是简单的 Python 脚本（容易崩、无状态管理）。而《三國志略》展示了高可用性（47个测试用例1秒跑完、有状态持久化机制、优雅的 API 异常自动降级离线机制）。
    *   **大模型仿真落地**：我们首次证明了在 Token 极其廉价的今天，用纯大模型替代传统策略游戏数值引擎是完全商业可行的，并且运行成本低到“一整局游戏不到5分钱”。
*   **核心收益**：通过游戏吸引极客、独立游戏人、AI 行业从业者的关注，展现涌现科技在**仿真演算、大模型应用架构设计**等企业级场景的交付实力，为未来的 B 端业务或更大型的 Agent 平台（如 OpenClaw 小龙虾）积攒首批开发者铁粉。

---

## 二、 宣发节奏与 Hype 策划（未来一个月）

为了保持项目的持续热度，我们将推广分为三个阶段：

### 阶段一：首发冷启动与技术社区铺设（第 1 周）
*   **发布渠道**：知乎博文、Bilibili 实机解说视频、GitHub 仓库开源。
*   **技术社区发帖**：
    *   **V2EX**：发布在 `AI` 或 `程序员` 板块，主打“纯大模型做游戏引擎的尝试，每一局只要5分钱，来提 Star 开源共创”。
    *   **稀土掘金 / SegmentFault**：撰写技术硬文，分析《三國志略》中如何设计 Prompt、处理 JSON 格式不稳定性，以及如何抓取思维 Token。
    *   **Hacker News / Reddit (r/LocalLLaMA)**：发布英文版本介绍，吸引全球 AI 开发者关注。

### 阶段二：KOL 精准触达与 Mod 裂变（第 2 - 3 周）
*   **操作策略**：邀请游戏界和 AI 界的 KOL 进行体验与合作（具体名单和切入点见下文）。
*   **共创活动**：
    *   在 GitHub 发起“写下你的历史，AI 帮你推演”共创活动。
    *   因为游戏是模块化设计，任何人在几分钟内写一个 `.json` 配置文件就能创造出一段全新的战役或人物。我们以此吸引粉丝自己写 Mod，并在 B 站或知乎分享他们的《建安异录》推演截图。

### 阶段三：100 Star 达成与“小龙虾（OpenClaw）”发布会（第 4 周）
*   **引爆点**：当 GitHub Star 突破 100 时，兑现承诺，发布 **OpenClaw（小龙虾）** 即时通信智能体客户端。
*   **运营事件**：
    *   玩家可以直接扫码在微信群或 Telegram 中和小龙虾智能体对话玩游戏。
    *   通过此举，将《三國志略》的热度顺畅平移到涌现科技的下一代核心产品 **OpenClaw** 上，实现“游戏导流，平台落地”。

## 三、 意见领袖（KOL）合作与定向邀请策略

我们将合作的 KOL 分为两大类：**科技/大模型垂直领域** 和 **硬核/策略/独立游戏领域**。

### 1. 科技与 AI 垂直领域 KOL
*   **目标对象**：
    *   微信公众号/知乎大 V：*量子位*、*机器之心*、*新智元*、*极客公园*。
    *   B 站 AI 极客博主：*同济子豪兄*、*秋叶aaaki*、*AIGC工坊*。
*   **话术与 Pitch 角度**：
    *   “大模型价格战打响后，除了聊天，真正的杀手级落地应用在哪里？”
    *   “纯大模型作为仿真引擎的可行性验证——一局游戏成本不到5分钱，重新定义文字生成类游戏。”
    *   “基于智能体（Agent）的高可用工程设计：如何解决 JSON 格式崩溃和延迟问题。”

### 2. 策略与独立游戏领域 KOL
*   **目标对象**：
    *   专业媒体与大 V：*游研社*、*机核网 (Gcores)*、*游戏葡萄*。
    *   B 站三国与策略游戏 UP 主：专注于《三国志》、《文明》、《太吾绘卷》的硬核博主。
*   **话术与 Pitch 角度**：
    *   “当曹操和刘备的对话不再是读剧本，而是由大模型根据当前兵粮数据实时辩论，这才是真正的军师体验！”
    *   “自由文本决策：你输入任何野路子战术，AI 都能接住戏，推演历史分叉。”
    *   提供“定制化福利”：为愿意评测的 KOL 制作他们自己为主角的特制 JSON 剧本（例如“机核网小编大闹汜水关”），让他们录制视频时极具整活效果。

## 四、 社群运营与日常裂变

1.  **玩家吐槽与“名场面”收集**：
    由于 AI 会生成天马行空的《建安异录》剧情（比如张飞打仗顺便去打劫了黄巾军，或者曹操被迫和某路诸侯结拜），在知乎和社群中设立一个“三國志略名场面吐槽”专栏，鼓励玩家分享他们的推演日志。
2.  **战绩导出功能引流**：
    游戏内置了 `--export-log` 导出 Markdown/JSON 战纪功能。引导玩家在各大平台发帖时，附上导出的精美 Markdown 战纪，文章底部自带我们的 GitHub 项目地址，形成自然的裂变环。
