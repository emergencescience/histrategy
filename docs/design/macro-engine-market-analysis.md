## 一、七类潜在玩家

除了用户提出的三种分辨率（宏观政策派、战役微操派、人物角色派），LLM 驱动的历史模拟游戏还有四类潜在玩家：

### Type 1: 宏观调控派 (Macro Strategist)

**画像**：25-45 岁男性为主，高学历，对历史有深度兴趣。喜欢 Paradox 大战略（EU4、Victoria 3）而非 Total War。享受"如果我改变税率会怎样"而非"我怎么排兵布阵"。

**规模**：
- 全球：100K-500K（Paradox 核心用户群）
- 中国：50K-200K
- 付费意愿：高（愿意为深度内容订阅）

**LLM匹配度**：⭐⭐⭐⭐⭐ — 宏观经济/政策推演是 LLM 的甜点区

### Type 2: 战役微操派 (Battle Tactician)

**画像**：18-35 岁男性，喜欢三国志系列、Total War、率土之滨。享受精确控制每支部队、计算兵力对比、地形优势。

**规模**：
- 全球：10M-30M（含三国志+Total War+手游策略）
- 中国：5M-20M（三国志战略版单款日活千万级）
- **红海，AAA 厂商重兵把守**

**LLM匹配度**：⭐⭐ — 精确战斗计算不是 LLM 的优势，确定性引擎才是

### Type 3: 人物角色派 (Character/RP Player)

**画像**：20-35 岁，ACGN 文化受众。喜欢 Crusader Kings、太阁立志传、火焰纹章。在乎角色关系、家族传承、个人恩怨。

**规模**：
- 全球：1M-5M
- 中国：1M-5M（太阁+CK 中文社区）
- 付费意愿：中等偏高

**LLM匹配度**：⭐⭐⭐⭐ — 角色对话和关系演化是 LLM 强项，但需要极强的 consistency

### Type 4: 叙事消费者 (Narrative Consumer) ⭐ 新增

**画像**：25-50 岁，喜欢读历史穿越小说、看历史纪录片。不想做太多决策，希望 AI 生成一段精彩的架空历史，自己像读小说一样体验。类似 AI Dungeon 但偏严肃历史。

**规模**：
- 中国：10M-50M（与网络小说读者高度重叠）
- 转化率极低（从"看"到"玩"有门槛）
- 但如果是"半自动推演+阅读"模式，转化率会显著提升

**LLM匹配度**：⭐⭐⭐⭐⭐ — LLM 天然擅长叙事生成

### Type 5: 教育型用户 (Educational User) ⭐ 新增

**画像**：教师、学生、历史爱好者、公务员考试备考者。用游戏来理解历史逻辑、权谋思维、制度演化。

**规模**：
- 中国：10K-100K（窄众但精准）
- 付费意愿：**非常高**（愿意为"学到东西"付费，参考得到/混沌大学模式）
- 这是知识付费领域，不是游戏领域

**LLM匹配度**：⭐⭐⭐⭐⭐ — 需要引用准确、逻辑连贯，恰恰是 LLM 的优势

### Type 6: 竞技/数值优化派 (Min-Maxer) ⭐ 新增

**画像**：20-30 岁，喜欢找最优解、破局、速通。会在论坛分享攻略、数值表、最优策略。

**规模**：
- 中国：1K-10K（小众但声音大）
- 不直接产生收入，但对社区建设至关重要

**LLM匹配度**：⭐⭐ — 他们需要的是可预测的数值系统，不是 LLM 的随机性

### Type 7: 社交/狼人杀派 (Social Diplomacy) ⭐ 新增

**画像**：20-35 岁，喜欢三国杀、狼人杀、外交类桌游。享受合纵连横、背叛、结盟的多人在线博弈。

**规模**：
- 中国：10M-50M（社交游戏大盘）
- 需要完整的多人基础设施
- 这是另一个赛道

**LLM匹配度**：⭐⭐⭐ — LLM 可以扮演 NPC 势力做外交，但核心是 PvP

## 二、市场规模估算（中国）

### 总量

| 玩家类型 | 潜在规模 | 转化率 | 可触达用户 | ARPU/月 | 年收入潜力 |
|---------|---------|-------|-----------|---------|-----------|
| Type 1 宏观 | 200K | 1-5% | 2K-10K | ¥30-50 | ¥0.7M-6M |
| Type 4 叙事 | 10M | 0.01-0.1% | 1K-10K | ¥15-30 | ¥0.2M-3.6M |
| Type 5 教育 | 100K | 0.5-2% | 500-2K | ¥50-100 | ¥0.3M-2.4M |
| **Type 1+4+5 交集** | — | — | **2K-15K** | **¥30-80** | **¥0.7M-14M** |

### 推理

1. **这不是一个大众产品**。浏览器端、文字为主、历史深度内容——天然筛掉了 99% 的游戏玩家
2. 但留下来的 1% 是非常忠诚的高价值用户——类似《得到》的用户画像
3. 年收入天花板在 ¥1M-10M 之间，对于 2-3 人团队是可维持的
4. 关键不是"多少用户"而是"用户多忠诚"——1,000 个年付 ¥500 的用户比 10,000 个免费用户有价值 50 倍

### 崇祯模拟器的参考

- 定价 ¥48 + Token 内购
- 55% 好评率，1,679 评价（估算 3.3-8.4 万份）
- 收入区间：¥1.6M-4M（一次性付费 + 内购）
- **关键洞察**：55% 好评意味着近半玩家不满意——但他们还是买了。说明**需求真实存在，产品没满足好**

## 三、战略建议：Type 1 为主，兼容 Type 4+5

### 核心理由

1. **LLM 的最强能力 = 宏观推演**。不是算兵力，是推演"如果我在 207 年实行屯田制，10 年后北方经济会怎样"
2. **竞争真空**。宏观历史模拟几乎没有中国团队在做，光荣/Paradox 不做中文深度内容
3. **品牌一致性**。Emergence Science = 用 AI 理解涌现现象。宏观历史模拟就是"社会复杂系统的涌现"
4. **你的个人优势**。你擅长经济/政策/法律层面的思考，这是 Type 1 引擎的天然设计者

### 不作 Type 2/3 的原因

- Type 2（战役微操）：需要 3D 引擎/实时战斗/数值平衡。30 人团队起步。不是 LLM 的甜点
- Type 3（人物角色）：需要海量事件树 + consistency 引擎。不是不能做，是不该第一个做
- Type 6（竞技）：需要精确可计算的确定性引擎，与 LLM 的随机性矛盾
- Type 7（社交）：需要完整的多人联机基础设施，先做好单人再考虑

### 优先级

```
Phase 1 (现在): Type 1 核心引擎 + Type 4 叙事输出
Phase 2 (3个月后): Type 5 教育功能（引用、注释、百科）
Phase 3 (6个月后): 评估 Type 3/6/7 的可行性
```

## 四、与竞品的差异化定位

| | 崇祯模拟器 | 三国志14 | Paradox EU4 | **三國志略 (宏观)** |
|---|---|---|---|---|
| 核心体验 | 批奏折/决策 | 微操战斗 | 大战略 | **用 AI 理解历史** |

核心差异：**别人让你"玩游戏"，我们让你"做实验"**。

## 五、结论

**集中力量做 Type 1 宏观历史引擎。"历史实验室"是你的 unique selling proposition。**

市场规模不大但精准。1,000 个深度用户比 10,000 个免费用户更有价值。关键是把"学到东西"做成核心体验——这不是游戏的副产物，而是产品本身。
