## 1. Executive Summary

### 1.1 一句话定位

> **一个开源、AI驱动的文本历史策略游戏——玩家扮演历史领袖，用自然语言做决策，AI实时推演世界变化。**

### 1.2 为什么做这个

2026年5月，青干工作室的《历史模拟器：崇祯》在 Steam 发售，48元买断+Token内购，B站爆红（寅子18小时直播，多视频10万+播放，80%次日留存）。这验证了一个事实：

**AI + 历史策略文本游戏 = 真实市场需求。**

但崇祯题材有天然天花板——海外认知度低，单一主角线性的「救大明」叙事限制了 replayability。我们选择 **三国**——全球5亿+潜在受众的文化IP，30年光荣《三国志》系列教育出来的市场，天然适合多势力、多主角、高 replayability 的策略游戏。

### 1.3 核心战略

| 维度 | 定位 |
|------|------|
| **技术路线** | Python CLI (Rich) → Web UI (后续) → Steam 发行 (Phase 3) |
| **AI模型** | 多 Provider 支持 (OpenAI / DeepSeek / 通义千问 / OpenRouter) |
| **开源策略** | MIT 开源核心引擎，付费卖历史剧本 DLC |
| **品牌绑定** | 深度嵌入 emergence.science 品牌，用户从游戏了解平台 |
| **变现** | 开源免费 (CLI) → 可选云服务 (托管游戏 / AI Credits) |

## 3. 产品设计

### 3.1 核心玩法循环

```
                   ┌─────────────────────┐
                   │  选择历史领袖/势力    │
                   └──────────┬──────────┘
                              ↓
                   ┌─────────────────────┐
                   │   季度军师报告       │ ← AI 生成当前局势分析
                   │   (世界状态更新)      │
                   └──────────┬──────────┘
                              ↓
          ┌─────────────────────────────────────┐
          │        玩家输入战略决策              │
          │  (自然语言: "联合孙权北上伐曹"       │
          │   或编号选择建议选项)                 │
          └────────────────┬────────────────────┘
                           ↓
          ┌─────────────────────────────────────┐
          │    AI 推演 + 引擎模拟               │
          │    (LLM生成叙事 + 数值结算)          │
          └────────────────┬────────────────────┘
                           ↓
                   ┌─────────────────────┐
                   │  世界反应 + NPC行动  │ ← AI 模拟各势力反应
                   │  (历史事件检查触发)   │
                   └──────────┬──────────┘
                              ↓
                   循环回到「季度军师报告」
```

### 3.2 核心机制

| 机制 | 说明 | AI 角色 |
|------|------|---------|
| **自然语言决策** | 玩家用中文/英文输入战略 | LLM 理解意图，映射到游戏状态变更 |
| **AI NPC 模拟** | 每回合各势力自主行动 | LLM 生成各领袖的战略决策 |
| **历史事件系统** | 预设关键事件 + AI 衍生事件 | LLM 判断事件触发条件和叙事生成 |
| **世界状态引擎** | 数值化国力/兵力/经济/民心 | LLM 输出 JSON 状态变化，引擎校验 |
| **多势力选择** | 可选曹操/刘备/孙权/袁绍等 | LLM 适配不同势力的叙事风格 |
| **离线模式** | 无需 API key 的规则引擎 | 无 AI，纯规则模拟 |

### 3.3 游戏模式

| 模式 | 描述 | AI需求 |
|------|------|--------|
| **离线模式** | 纯规则引擎，模板文本 | 无 |
| **AI故事模式** | LLM 驱动叙事 + 规则结算 | 中 (每回合1次API调用) |
| **AI完全模式** | LLM 驱动叙事 + AI NPC + AI结算 | 高 (每回合3-5次API调用) |
| **多人模式 (Future)** | 多个玩家扮演不同势力 | P2P/Server |

### 3.4 首个可玩 Scenario

**「190年：群雄逐鹿」**

- 时间起点：初平元年（董卓入京后）
- 可选势力：曹操、刘备(初期)、孙坚、袁绍、袁术、董卓、刘表、公孙瓒
- 关键事件：讨董联盟、迁都长安、孙坚得玉玺、诸侯内战
- 胜利条件：统一北方 / 称帝 / 生存到指定年份

### 3.5 用户界面

**Phase 1 (当前)**: Rich 终端 CLI
- ASCII 艺术标题
- 彩色势力信息面板
- 选项编号 + 自由输入混合
- 历史日志滚动

**Phase 2 (未来)**: Web UI (SSR + htmx / React)
- 地图渲染（Papapy.js 或 Canvas）
- 势力关系图
- 诏书编辑器
- 历史时间轴

**Phase 3 (远期)**: Steam 发行
- 集成 Steam SDK
- Steam 成就/云存档/创意工坊

## 4. 商业模型 (Monetization Strategy)

### 4.1 核心理念

**开源免费 + 可选增值服务**。不学青干的 Token 收费模式（争议大），而是：

| 层级 | 价格 | 内容 |
|------|------|------|
| **免费 (MIT)** | ¥0 | 核心引擎 CLI，三国剧本「190年群雄逐鹿」，离线模式 |
| **历史DLC** | ¥9-19 | 新剧本(春秋/战国/罗马/安史之乱) |
| **云服务** | ¥19/月 | 托管游戏存档、AI Credits 池、Web UI 访问 |
| **Brand DLC** | ¥6 | emergence.science 品牌皮肤包（支持平台发展） |

### 4.2 与 emergence.science 协同

- 游戏内可接入 emergence.science 的 AI Credits 系统
- 玩家在游戏内消耗的 AI token 走 emergencescience 结算
- 游戏本身是 emergence.science 品牌的最大展示案例
- 长期：历史策略游戏作为 emergence.science 平台的「旗舰 skill」

### 4.3 成本模型

| 成本项 | 当前 (CLI) | Phase 2 (Web) | Phase 3 (Steam) |
|--------|-----------|--------------|-----------------|
| AI API 调用 | 玩家自付 | 玩家自付/可选云池 | 玩家自付 |
| VPS 托管 | $10-20/月 | $30-50/月 | $50-100/月 |
| Steam 上架费 | — | — | $100 一次性 |
| 内容创作 | $0 (开源社区) | $0 (开源+AI生成) | $0 |

## 5. 技术约束

- **Python 3.10+** (当前 stack)
- **Rich CLI** — 终端渲染
- **OpenAI 兼容 API** — 支持 OpenAI / DeepSeek / 通义千问 / OpenRouter
- **Pydantic** — 结构化数据验证 + LLM JSON output 校验
- **httpx** — 异步 HTTP 客户端
- **无数据库** (当前阶段 JSON 文件存档)
