### 2.1 合法性系统（Legitimacy Engine）

**核心指标**: `legitimacy`（0-100）

**影响因素**:

| 事件 | 效果 | 衰减 |
|------|------|------|
| 控制洛阳 | +20（一次性） | 永久 |
| 迎汉献帝 | +40（一次性） | 永久 |
| 灭曹操 | +15 | 永久 |
| 以汉室名义发诏书 | +3/次 | 每季 -1 |
| 与汉室宗亲结盟 | +5 | 永久 |
| 无故攻汉室宗亲 | -20 | 每季 -2 |
| 高税率 (>40%) | -1/季 | 持续 |
| 低税率 (<15%) | +1/季 | 持续 |
| 有诸葛亮 | +10 | 永久 |
| 民变/饥荒 | -15 | 持续到解决 |

**合法性效果**:

```
legitimacy > 80:  外交成功率 +30%，人才投奔率 ×2
legitimacy > 60:  外交成功率 +15%，税收效率 +10%
legitimacy < 30:  外交成功率 -20%，叛乱风险 +15%/季
legitimacy < 10:  将领叛逃概率 +5%/季，民心自动下降
```

**开发量**: ~150 行（新引擎模块 + FactionState 加字段）

### 2.2 粮食系统（Granary System）

**核心指标**: `food_production`, `food_consumption`, `food_surplus`

**公式**:

```python
# 每季生产
food_production = fertility × (development/100) × season_multiplier × population × 0.1
# season_multiplier: 春0.3, 夏1.0, 秋1.2, 冬0.05

# 每季消耗
food_consumption = total_troops × 0.5 + total_population × 0.02

# 盈余
food_surplus = food_production - food_consumption
```

**效果**:

```
food_surplus > 2000:  人口增长 +2%/季，民心 +1/季
food_surplus > 0:     人口稳定
food_surplus < 0:     存粮消耗，民心 -1/季
food_surplus < -5000:  饥荒！人口 -5%/季，民心 -5/季，合法性 -10
```

### 2.3 分封 & 任命系统

**核心概念**: 每个领地需要任命一个太守（Governor），太守属性影响领地产出。

**官职层次**:

```
皇帝 (Emperor) — 合法性 > 80 且控制洛阳时可称帝
  ├── 丞相 (Chancellor) — 智力影响全国税收效率
  ├── 大司马 (Marshal) — 统率影响全国征兵效率
  ├── 太尉 (Minister) — 政治影响全国发展成本
  └── 太守 (Governor) × N — 每城一个，五维影响该城产出
```

**任命效果公式**:

```python
# 太守对领地的加权
governor_bonus = (
    governor.politics × 0.4  +  # 政治 → 税收
    governor.intelligence × 0.3 + # 智力 → 发展速度
    governor.leadership × 0.2  +  # 统率 → 征兵效率
    governor.charisma × 0.1       # 魅力 → 民心/人口增长
) / 100

# 无太守时，bonus = 1.0（基础值）
tax_revenue = base_tax × (1.0 + governor_bonus)
development_speed = base_speed × (1.0 + governor_bonus)
```

**分封**（新指令）:

```
/分封 黄忠 于 宛城 — 任命黄忠为宛城太守
  · 效果: 宛城税收/发展/征兵效率受黄忠属性加成
  · 花费: 500金（俸禄）
  · 条件: 黄忠必须在你麾下
```

**开发量**: ~200 行（角色数据填充 + 任命逻辑 + Agent 集成）

## 四、预期收益

### 4.1 游戏体验收益

| 功能 | 玩家获得什么 |
|------|------------|
| **粮食系统** | 不再只看金库。粮食盈余 → 人口红利 → 长期国力。高下立判。 |
| **合法性** | 「我打曹操不是侵略，是奉天讨贼」— 每个行为有政治代价 |
| **分封** | 黄忠守宛城 vs 蔡瑁守宛城，税收差 30%。人才终于有意义。 |
| **屯田** | 战后河南的恢复——从「废墟」到「粮仓」的叙事弧 |
| **诏书** | 「以汉献帝名义诏告天下」→ 合法性 +3 → 曹操的部下开始动摇 |

### 4.2 差异化收益

| vs 崇祯模拟器 | 我们的优势 |
|--------------|-----------|
| 崇祯: 纯 LLM 说「陛下圣明」 | 我们: 粮食不够就是会饿死人——引擎计算的 |
| 崇祯: 没有人才管理 | 我们: 黄忠统率 95 vs 蔡瑁统率 60，差距可量化 |
| 崇祯: 锁 API | 我们: 开源，引擎是本地的 |

### 4.3 传播收益

分封系统天然适合 **存档分享**:
> 「我的刘表存档: 诸葛亮守襄阳(智力100→税收×1.5)，黄忠守宛城(统率95→征兵×1.45)，来试试能不能攻破我的防线」

每份存档 = 一个传播节点。
