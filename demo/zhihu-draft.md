# 《三國志略》— 一款 AI 驱动的历史策略游戏，完全开源

## 缘起

2026 年，AI + 历史策略文本游戏正在证明自己是一个真实的市场需求。玩家渴望的不是堆数值的 SLG，而是真正有叙事深度、决策有实质影响的历史体验。

但现有的大多产品受限于单主角线性的叙事结构，replayability 有限。

所以有了《三國志略》。

我们选择三国——这是一个全球 5 亿+ 潜在受众的文化 IP，30 年光荣《三国志》系列教育出来的市场，天然适合多势力、多主角、高 replayability 的策略游戏。从 190 年董卓乱政开始，你可以在曹操、刘备、孙坚、袁绍等势力中选择一方诸侯，用你的决策改寫歷史。

## 怎么玩

安装：
```bash
pip install histrategy
# 或从 GitHub 克隆
git clone https://github.com/emergencescience/histrategy
```

玩（即使没有 API Key）：
```bash
histrategy
```

你扮演一方诸侯，每个季度做一次战略决策。AI 实时推演你的决策的后果——外交、军事、内政、间谍，你的每一个选择都可能改变历史的走向。

## AI 叙事示例

> *初平元年春正月，天下之势如鼎沸之水，诸侯各怀异志。董卓据洛阳，挟天子以令诸侯，然暴虐失民心。袁绍得河北之地，拥兵十万，以四世三公之望，被推为讨董盟主，然其人多谋寡断，恐难成大事。主公散家财、发矫诏于兖州，天下忠义之士闻风而动，此刻正是一展鸿图之机……*

这是 DeepSeek V4 生成的叙事——不是预设文本，而是根据你选择的势力和游戏状态实时生成的。每次游戏都是独一无二的故事。

## 游戏特色

- **决策影响叙事**：你输入的不再是"选 A 或 B"的单选题。输入「联合袁绍讨伐董卓」，AI 会解析你的意图并生成特定的后果——袁绍可能同意联军但要求你做先锋，也可能因忌惮你的实力而拒绝。
- **后果系统**：每个决策后你会看到即时的回馈：「⚡ 你的决策：「联合袁绍」→ 袁绍同意结盟，但要求你先攻洛阳」
- **人物性格驱动**：曹操多疑、董卓残暴、刘备仁德——性格影响 NPC 的每一次决策和外交回应
- **多势力开局**：曹操（挟天子潜力）、刘备（仁德民心）、孙坚（江东基业）、袁绍（四世三公）各有独特开局叙事和战略选择

## 技术架构

- **Python 3.10+** + **Rich CLI**（漂亮的终端界面）
- **多 Provider 支持**：DeepSeek / OpenAI / 通义千问 / OpenRouter 自动检测
- **知识库驱动**：20+ 历史人物、8 大势力、19 个地域，角色性格影响行为
- **记忆系统**：存档到 `~/.histrategy/player_memory.json`，历史决策可追溯
- **事件链**：讨董之盟、诸侯分裂、迎奉天子——每个阶段都有独特叙事
